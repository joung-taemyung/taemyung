### B-1 · 02 AI가 놓친 문제를 1개 이상 직접 찾아 짝과 비교 (15:12–15:20) { #b1-missed .step data-tool="Claude Code" }

## 채팅 경로 — Claude Code를 못 쓸 때 {#chat-path}

claude.ai 또는 ChatGPT에 파일을 올려 같은 일을 합니다([실습 A의 채팅 경로](lab-a.md#chat-path)와 같은 방식).
