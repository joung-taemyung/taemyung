### 6일이 끝나면 할 수 있는 것 {#goals}

<div class="tf-rules" markdown>

1. **AI를 일에 맞게 고르고, 근거를 요구하고, 결과를 검증해 쓴다** — LLM이 답을 만드는 원리, ChatGPT · Claude · Claude Code 가운데 고르는 법, 프롬프트에서 컨텍스트 설계까지.
2. **내 PC를 AI 작업실로 만든다** — VS Code · Claude Code · Git · GitHub로 일하고, 브랜치 · PR · worktree · 커밋 이력으로 AI의 작업을 나누고 합치고 되돌린다.
3. **데이터로 위험을 읽고 결정한다** — 탐색 · 정제 · 특성 · SQL · 텍스트 점수화 → 연체 확률 예측과 설명 → 한도 최적화 · 시뮬레이션 · 조기 경보 자동화.
4. **서비스로 만들어 내보낸다** — 웹 · API · 실시간 연동 · DB · RAG 챗봇 · 대시보드 배포, 그리고 되돌릴 수 없는 일 앞에 사람 승인을 두는 에이전트 설계.
5. **우리 회사 도입안을 쓴다** — 팀 솔루션 킷 `v1.0`(SOP · 보수안 ROI · 근거표)과 개인 도입 기획서 · KPI · ROI.

</div>

!!! note "실습에서는 이렇게 지킵니다"

    알림 · 메일의 '자율 제어'는 **AI가 초안을 만들고 사람이 승인**하는 방식으로 실습합니다. 메일은 모두 DRY RUN(실제 발송 없음)입니다. 코드를 처음부터 쓰는 연습이 아닙니다. **AI에게 시키고 · 읽고 · 실행해 확인하고 · 커밋으로 남기는** 연습입니다.

## 3. 운영 규칙 {#rules}

<div class="tf-rules" markdown>

1. **사람이 최종 결정한다.** 한도 변경 · 선적 보류 · K-SURE 통지 · 바이어 발송은 AI가 초안을 만들고 사람이 승인합니다. 메일은 모두 DRY RUN입니다.
2. **기본은 가상(합성) 데이터.** 회사 실데이터 · 개인정보는 어떤 AI 도구에도, 공개 저장소 · 공개 앱에도 올리지 않습니다 — 익명화본도. 자사 숫자가 들어가는 개인 도입 기획서는 익명화 체크리스트를 통과한 값만 쓰고 비공개 폼으로만 냅니다 → [데이터 위생 5원칙](setup.md#hygiene) · [저장소 · 앱 규칙](setup.md#repo-hygiene).
3. **근거를 보인다.** AI가 준 문장은 원문에서 찾고, 숫자는 공식 · 코드로 다시 계산합니다. 검증 전까지는 가설입니다.
4. **모델은 이름보다 계층과 일의 종류로 고른다.** 모델 이름과 메뉴는 자주 바뀝니다. 화면의 이름이 안내와 달라도 같은 계층(최상위 · 주력 · 경량)에서 일에 맞게 고르면 됩니다.
5. **새 일 = 새 채팅.** 대화가 길어지면 AI가 앞의 지시를 놓칩니다.
6. **허락 창은 읽고 승인한다.** Claude Code가 묻는 것은 무엇을 · 어디에 · 지우는지 세 가지를 읽고 승인합니다. 파일 삭제 · 강제 push · `git reset --hard`는 거절합니다.
7. **막히면** 노트북 위에 빨간 표시(스티커 등, 다 끝나면 초록) → [FAQ](faq.md) → 손들기. 바로 답하기 어려운 실무 질문은 메모해 두었다가 쉬는 시간이나 다음 날 아침에 물어 주세요.
8. **회사 보안 규정이 이 사이트의 안내보다 우선합니다.**

</div>

### Streamlit Community Cloud {#streamlit}

1. [share.streamlit.io](https://share.streamlit.io) → **Continue with GitHub**로 로그인합니다.
2. **Create app** → Repository **내 개인 저장소**(과정 템플릿에서 만든 것) · Branch `main` · Main file `app/streamlit_app.py` · App URL `traderisk-t{조}-{번호}`.
3. **Advanced settings**에서 Python 버전을 **3.13**으로 고르고 **Secrets 칸은 비워 둔 채** **Deploy**를 누릅니다(비우면 앱이 모의 모드로 끝까지 돕니다).
4. 저장소 `main`에 병합하면 1–2분 뒤 자동으로 다시 배포됩니다.

- 12시간 동안 아무도 접속하지 않으면 앱이 잠듭니다. 화면의 깨우기 버튼을 누르면 1–2분 뒤 돌아옵니다(수업일 아침에는 강사가 미리 깨웁니다).
- 비공개 앱은 계정당 1개뿐이라 수업 앱은 **공개 저장소 + 합성 데이터**로 만듭니다.
- 앱이 막히면 강사 앱 주소로 진행합니다. 자세한 순서는 [5일차 실습 B6](day5/lab-b.md#b6)에 있습니다.

### 앱의 AI 키(선택) {#llm-key}

- 실습은 **키 없이(모의 모드)** 끝까지 합니다. 실제 AI 초안을 보고 싶을 때만, 강사가 안내하는 경우에 한해 하루 사용 한도가 있는 개인 키를 받습니다.
- 키를 넣는 곳은 **Streamlit Secrets 칸**뿐입니다. 대화창 · 채팅방 · 저장소 · 스크린숏에는 넣지 않습니다.
- 키가 노출되었으면 바로 강사에게 알립니다 — 키를 폐기하고 새로 받습니다(비난하지 않습니다).
- Secrets 형식은 과정 저장소의 [`app/.streamlit/secrets.toml.example`](https://github.com/brainini/tradefin-ai-2026/blob/main/app/.streamlit/secrets.toml.example)에 있고, `<…>` 자리에 강사가 안내한 주소 · 키를 넣습니다. 키를 비워 두면 앱은 모의 모드(템플릿 초안)로 돕니다.

## 5. 자료는 언제 열리나 {#release}

**1–6일차의 모든 쪽**(개요 · 이론 요약 · 실습 가이드 · 프롬프트)과 **1–5일차 슬라이드 PDF**는 지금 열려 있습니다. 파일은 실습 쪽의 **입력 파일 받기** 카드나, 내 저장소 터미널의 `uv run python tools/get_day_files.py N`(N = 일차)으로 받습니다.

다만 **정답이 담긴 파일**은 실습에서 먼저 내 결과를 만든 뒤 견주도록 원래 시각에 엽니다 — 전날 결과가 담긴 다음 날 시작 파일 · 골든셋 · 강사 모델 · 기대값 테스트 · 정답 요약이 그렇습니다.

- 사이트 카드에는 잠금 표시 <span class="tf-chip tf-chip--lock">15:35 공개</span>가 붙고, **그 시각이 지나면 저절로 받기 단추**로 바뀝니다(새로 고침만 하면 됩니다).
- `get_day_files.py`는 그 전에는 **열기 전**이라고 알려 주고 그 파일만 받지 않습니다. 시각이 지난 뒤 같은 명령을 다시 실행하면 받습니다. 꼭 필요하면 뒤에 `--now`를 붙입니다.
- 6일차의 위기 카드 · 데이터 팩 · 인젝트와 6일차 슬라이드 완성판은 그 시각에 **자동으로 올라옵니다**. 사이트 카드는 1–3분 뒤에 받기 단추로 바뀝니다.
