## 이 사이트 쓰는 법 {#how}

<div class="grid cards tf-cols-2" markdown>

-   :material-book-open-page-variant-outline:{ .lg .middle } **일차 쪽은 네 갈래**

    **개요**(목표 · 시간표 · 시연 · 파일 받기 · 결과물) · **이론 요약** · **실습 A**(4–5교시) · **실습 B**(6–7교시). 6일차는 해커톤 쪽(위기 카드 · 솔루션 킷 · 심사 · 제출)이 더 있습니다.

-   :material-format-list-checks:{ .lg .middle } **실습은 단계 카드로**

    단계마다 **내가 할 일 → 프롬프트 → AI가 하는 일 → 확인**. 오른쪽(휴대폰은 화면 아래) 진행 카드에 지금 단계와 완료 수가 보입니다. 완료 표시는 **이 브라우저에만** 저장됩니다.

-   :material-source-branch:{ .lg .middle } **길은 두 가지**

    기본은 내 PC의 VS Code + Claude Code + GitHub. Claude Code를 못 쓰면 실습 쪽의 **채팅 경로**(ChatGPT · Claude 웹 + GitHub 웹)로 같은 결과를 만듭니다. 설치가 막힌 PC는 [Codespaces](setup.md#codespaces).

-   :material-content-copy:{ .lg .middle } **프롬프트 · 파일**

    프롬프트 상자 오른쪽 위 :material-content-copy: 로 통째로 복사하고 `{중괄호}` 칸만 바꿉니다. 입력 파일은 실습 쪽 **입력 파일 받기** 카드에 있고, 비교용 기준 파일은 정한 시각에 저절로 열립니다(잠금 표시 <span class="tf-chip tf-chip--lock">15:35 공개</span>).

</div>

!!! warning "AI 대화창은 외부 채널입니다"

    실습 데이터는 전부 가상(합성)이거나 공개 공시입니다. 회사 실데이터 · 개인정보는 어떤 AI 도구에도, 공개 저장소에도 올리지 않습니다 — 익명화본도. 올려도 되는 것과 안 되는 것은 [사전 준비 → 데이터 위생 5원칙](setup.md#hygiene)에 있습니다. 회사 보안 규정이 있으면 그것이 이 사이트의 안내보다 우선합니다.
