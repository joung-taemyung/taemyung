# 위기 카드 — 받는 법 · 읽는 법 · 데이터 팩

**카드 한 장 = 1쪽 분량의 위기 대응 시나리오 + 300행 이내의 채권 데이터 팩.** 카드를 받는 순간부터 [실습 A Step 1](lab-a.md#a-card)이 시작됩니다.
</div>

!!! info "카드 내용은 10/21(수) 09:28에 자동으로 열립니다 — 봉투는 09:31"

    위기 카드는 **종이(A5) 봉투**로 받습니다. 카드 원문 · 데이터 팩 · 팀 팩 · ROI 완성본은 09:28에 저절로 열려 아래 [카드 파일](#files)에 링크가 생기고(사이트는 1–3분 뒤), 팀 저장소에서는 `uv run python tools/get_day_files.py 6`이 바로 받습니다. 그 전에는 이 쪽에서 카드가 어떻게 생겼고 어떤 순서로 읽는지만 봅니다 — 실제 위기는 예고 없이 옵니다.

## 카드는 이렇게 받습니다 {#how}

| 무엇 | 언제 | 누구에게 | 형태 |
|---|---|---|---|
| **주카드** 1장 | **09:31** 개봉 | 팀마다 다른 카드(5종) — 보통 조 번호와 같은 번호(1조 ①, 2조 ② …) | A5 종이 1쪽 = 파일 `card1`–`card5` |
| **데이터 팩** · **팀 팩** | **09:28** 자동 공개 | 전 팀 — 팀 팩은 **우리 조 번호의 파일만** | `d6_crisis_pack.xlsx` · `team_0{조}.xlsx` |
| **ROI 완성본** | 09:28 자동 공개 | 카드마다 하나 — 실습 B Step 5에서 | `roi_kpi_card{카드}.xlsx` |
| 2단계(일부 카드) | 11:15 | 해당 팀만 — 강사 · 조교가 직접 알려 줍니다 | 말 · 메일 카드 + 파일 |
| **공통 인젝트 1** | **11:30** | 전 팀 동시 | 종이 → 같은 시각에 파일 |
| **공통 인젝트 2** | **13:15** | 전 팀 동시 | 종이 → 같은 시각에 파일 |
| 변형 카드 | 09:31 | 공공조달 업무 수강생이 한 팀에 셋 이상일 때만 주카드에 더합니다 | 종이(파일은 09:28 자동 공개) |

- 카드 파일은 번호로만 받습니다 — 우리 팀 카드 번호만 엽니다.
- 1차 서면 피드백 봉투(09:00)와 위기 카드 봉투(09:31)는 다른 봉투입니다. 위기 카드는 신호가 있을 때까지 열지 않습니다.

## 카드 한 장에 들어 있는 것 {#anatomy}

| 칸 | 내용 | 먼저 보는 역할 |
|---|---|---|
| 상황(T+0) | 오늘 아침 벌어진 일 — 바이어 · 국가 · 금액 · 요청 | 전원 |
| 트리거 데이터 | 데이터 팩에서 바뀌는 값 — 어느 바이어의 무엇이 얼마나(`buyer_changes` · `invoice_changes` · `scenarios`) | ① 데이터 |
| 답해야 할 질문 5 | 팀이 오늘 답할 질문 — 역할마다 나눈다 | 역할마다 |
| 기대 산출물 | 표 · SOP 장 · 메시지 초안 — 카드마다 결과물의 모양이 다릅니다 | ⑤ SOP · 발표 |
| 실제 앵커(뒷면) | 카드가 기대고 있는 실제로 있었던 일 | ④ 규정 · 근거 |
| 용어 상자(뒷면) | 카드에 나오는 무역금융 용어 풀이 | 전원 |

- 카드의 상황과 숫자는 <span class="chip chip--virtual">[교육용 가정]</span>입니다. '실제 앵커'만 실제로 있었던 일이고, 실존 피해 기업의 이름은 쓰지 않습니다.
- **최소 완료 기준**: 질문 5개 중 3개 + 인젝트 2개 대응. [심사 기준](judging.md#criteria)의 1–4점 설명은 카드와 상관없이 같습니다.
- 카드가 묻는 무역금융 판단(어느 위험인지, 통지할지, 선적을 멈출지)은 팀이 근거를 달아 내립니다. AI는 계산 · 초안 · 근거 찾기를 돕고, **결정은 사람**이 합니다.
- 오전 시연 1의 회생 바이어는 시연용 가정입니다 — 어느 카드의 데이터에도 그 사건은 없습니다. 같은 바이어 번호가 우리 카드 대상에 있어도 회생으로 다루지 않습니다.

## 카드 읽는 순서 — 09:31–09:50 {#read}

<div class="tf-rules" markdown>

1. **상황 요약 한 줄** — 누가 · 무엇을 · 언제까지(3분, 팀 전원이 같은 카드) → 역할 이슈 · README 1번
2. **변수 매핑** — 바뀌는 것이 PD · LGD · EAD · 지연일 · 환율 · 결제조건 중 무엇인지, 어느 시트의 어느 열인지 — 프롬프트 [S1](../prompts/day6.md#s1)로 표 초안 → [Step 1](lab-a.md#a-card)
3. **숫자 대조** — AI 표의 영향 바이어 수를 팀 팩 `card` 시트의 `n_buyers`와 견준다(엑셀로 세지 않는다)
4. **사람이 결정할 항목 표시** — 한도 변경 · 선적 보류 · K-SURE 통지 · 바이어 발송 → 빨간색
5. **질문을 역할에 나누기** — 질문마다 담당 역할(①–⑤) · 넘길 시각 · 근거가 필요한지(④에게)

</div>

## 데이터 팩 읽는 법 {#pack}

**팀 팩** `team_0{조}.xlsx` — 우리 카드에 필요한 조각만 모은 파일입니다. 먼저 이 파일로 시작하고, 팀 저장소의 **`data/input/`**에 둡니다.

| 시트 | 무엇 | 쓰는 역할 |
|---|---|---|
| `README` | 우리 팀 · 카드 · 기준일(T+0) · 시트 안내 · 만들 파일 이름 | 전원 |
| `card` | 카드 요약 · 질문 5 · **`n_buyers`(영향 바이어 수)** | 전원 |
| `buyer_changes` | 바이어 단위 변경. 빈칸 = 그대로, 반영한 줄은 `applied`에 ✔ | ① |
| `invoice_changes` | 인보이스 단위 변경(미결 인보이스에 반영) | ① |
| `scenarios` | S0와 우리 카드의 시나리오 행(PD 배수 · LGD · 환율 · 금리) → EL 표의 열 | ③ |
| `buyers` · `open_inv` | 대상 바이어의 지금 값 · 미결 인보이스 | ① · ③ |
| `deadlines` | **카드 반영 전** 기한(D+30 · 사고발생통지) — 카드 변경을 넣어 다시 계산하는 것이 ③의 일 | ③ |
| `limit_realloc` | 한도 재배정 표 — 왼쪽은 지금 값, 오른쪽 빈칸을 팀이 채움(감액 30% 이상 = 사람 승인) | ③ |

**전체 데이터 팩** `d6_crisis_pack.xlsx` — 다섯 카드 전체가 한 파일에 있습니다. 필터로 우리 카드 번호만 골라 씁니다. `budget` 시트(가상 기업의 연간 채권관리 · 대외자문 예산)는 ROI 완성본의 비용 근거입니다. 시트별 CSV(`d6_crisis_pack_{시트}.csv`)는 스크립트나 채팅 AI에 올리기 편한 형식입니다.

## 인젝트 — 진행 중에 바뀌는 상황 {#injects}

| 인젝트 | 시각 | 받는 팀 | 무엇을 남기나 |
|---|---|---|---|
| **1** | **11:30** | 전 팀 공통 | 카드가 시키는 계산을 스크립트로 → SOP의 해당 장에 한 줄 |
| **2** | **13:15** | 전 팀 공통 | 사람이 내린 결정 · 근거 · 결정자 · 시각 → `docs/decision_log.md` |

- 투입 시각에 **전원 손을 멈추고**(기립 신호) 낭독을 듣습니다. 10분 타이머 안에 팀이 대응 방향을 정합니다.
- 인젝트 카드에는 '할 일' 표(역할마다 한 줄)와 '사람이 결정할 것'이 적혀 있습니다. 내용은 미리 알려 드리지 않습니다 — 프롬프트 [I1](../prompts/day6.md#i1) · [I2](../prompts/day6.md#i2)는 카드의 '할 일' 표를 읽게 만들어 두었습니다.
- 인젝트 반영은 심사 기준 ①에 들어갑니다 — 3점은 1개 반영, 4점은 2개 반영 + 평상시(S0) 대비 비교.
- 낭독 · 종이 카드가 먼저이고, 파일은 그다음입니다. 투입 시각에 `get_day_files.py 6`을 한 번 더 실행한 PC의 `labs/day6/injects/`로 들어옵니다 — 커밋되지 않는 폴더라 I1 · I2를 보내는 사람(R3)의 PC에서 실행합니다. 같은 시각에 아래 [카드 파일](#files)에도 링크가 생깁니다(1–3분 뒤).
