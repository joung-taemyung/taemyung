# 심사 기준 — 근거와 재현에 40점

아래 1–4점 설명은 심사위원이 쓰는 기준과 글자 그대로 같습니다. 점수 칸 없는 공개본 `judging_rubric.xlsx` · `.md`는 [루브릭 파일](#files)에서 받습니다.
</div>

심사 기준은 화려함이 아니라 **근거가 있는가, 다른 사람이 다시 돌릴 수 있는가**입니다. 기준 ① · ③은 [솔루션 킷](kit.md)에서, ② · ④는 SOP와 근거표에서, ⑤는 ROI 시트에서, ⑥은 7분 데모에서 봅니다.

## 기준 6개 × 1–4점 {#criteria}

| 기준 | 가중치 | 1점 | 2점 | 3점 | 4점 |
|---|---|---|---|---|---|
| ① 스트레스 테스트 완결성 | 25 | 카드 질문 2개 이하, 숫자 없음 | 질문 3–4개, 숫자 일부(EL 또는 한도) | 질문 5개 + EL · 한도 변화 숫자 + 인젝트 1개 반영 | + 인젝트 2개 반영, S0 대비 비교, 재현 가능(파일 · 커밋) |
| ② 근거 · 검증 · 사람 승인 | 20 | 근거 없음 | 일부 조치에만 근거 | 모든 조치에 조항 · 파일 근거, 사람 승인 지점 표시 | + P6-2 검증으로 고친 이력, '확인 필요' 목록 |
| ③ 솔루션 킷 품질 | 20 | README 없음, 파일 흩어짐 | README 일부, 폴더 일부 | README 5항목 + 폴더 6개 + `v1.0` 릴리스 | + 제3자가 5분 안에 재현, 비밀값 · 실데이터 0, 이슈 · PR 이력 |
| ④ SOP 실행 가능성 | 15 | 일반론 | 단계는 있으나 담당 · 기한 없음 | T+0/24h/72h/1주 × 담당 · 도구 · 승인자, RACI | + 정량 발동 · 종료 조건, 커뮤니케이션 초안(승인 전) |
| ⑤ ROI · KPI 타당성 | 10 | 숫자 없음 또는 과장 | 산식만 | 기준선 + 보수 · 기준 · 낙관 3안 | + 중앙값 10%와 비교, 신뢰도 보정, 측정 방법 · 주기 |
| ⑥ 데모 · 전달 | 10 | 7분 초과 또는 라이브 실패 후 대안 없음 | 결론이 늦다 | 결론 먼저, 데모, 7분 준수 | + Q&A에 숫자 · 근거로 답, 팀원 전원의 역할 언급 |

- 4점은 3점의 내용을 모두 채운 뒤 '+' 뒤의 것까지 해낸 경우입니다.
- 1–4점 설명은 카드와 상관없이 같습니다(카드 난이도 보정 없음). 카드별 최소 완료 기준은 **질문 5개 중 3개 + 인젝트 2개**입니다.
- ⑤의 '중앙값 10%'는 재무 부문 AI 도입 ROI의 중앙값(2025년 재무 임원 조사)입니다 — 14시 브리핑에서 다룹니다([이론 요약 4장](theory.md#ch4-roi)).

## 총점 계산 {#formula}

**총점 = Σ(점수 ÷ 4 × 가중치)** — 100점 만점입니다. 심사위원(한태구 · 이창규, 필요하면 1명 추가)이 각자 채점한 뒤 평균합니다.

<div class="tf-scroll" markdown>

| 예 | ① | ② | ③ | ④ | ⑤ | ⑥ | 총점 |
|---|---|---|---|---|---|---|---|
| 점수(1–4) | 3 | 4 | 3 | 3 | 2 | 3 | |
| 환산 | 18.75 | 20 | 15 | 11.25 | 5 | 7.5 | **77.5** |

</div>

<small>계산 방법을 보여 주는 <span class="chip chip--virtual">[가상 예시]</span>입니다.</small>

- **동점**이면 ② 평균 → ① 평균 → 심사위원 합의 순서로 정합니다.
- 체크포인트에 못 미쳐 강사 정답본으로 합류했어도 **재현 기록**(README 3번 '사용한 경로')을 남기면 감점하지 않습니다.
