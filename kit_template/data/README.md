# data — 카드를 반영한 데이터 (가상 데이터만)

| 파일 | 내용 | 만드는 사람 → 받는 사람 |
|---|---|---|
| `d6_{카드}_scored.csv` | 카드의 트리거 변경을 반영한 바이어 점수 파일 | ① 데이터 → ② 모델·등급 |
| `d6_{카드}_open_inv.csv` | 카드를 반영한 미결 인보이스 | ① 데이터 → ③ 한도·시나리오(조기 경보) |
| `change_log.csv` | 바뀐 행 기록: `buyer_id` · 열 · 전 값 · 후 값 · 근거(카드 · 시트) · 적용 시각 | ① 데이터 |

- `{카드}` 자리에는 카드 번호를 씁니다(예: `d6_2_scored.csv` · `SOP_2.md`).
- 바뀐 행 수가 카드의 `buyer_changes`와 같은지 확인합니다(역할 ①의 완료 체크).
- **이 폴더에는 과정의 가상 데이터만** 올립니다. 회사 실데이터 · 익명화본 · 개인정보는 올리지 않습니다.
