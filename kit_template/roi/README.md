# roi — ROI · KPI

| 파일 | 내용 | 담당 |
|---|---|---|
| `roi_kpi.xlsx` | 팀 ROI 3안(보수 · 기준 · 낙관) · 운영비 시나리오 — 과정 양식 `roi_kpi_template.xlsx`에서 시작 | ③ 한도·시나리오·ROI |

- **보수안부터** 씁니다. 숫자마다 근거나 [교육용 가정]을 붙입니다.
- 운영비 = 사용자 × 호출 × 일 × 단가.
- KPI는 기준선 · 목표 · 측정 방법 · 주기를 함께 적습니다. "전수조사 시간 90% 단축" 같은 문장은 목표의 예일 뿐 근거가 아닙니다 — 기준선은 1주 타임로그로 잽니다.
- 개인 '나만의 KPI · ROI'(`d6_roi__T{조}-{번호}.xlsx`)는 이 저장소에 올리지 않고 비공개 폼으로 냅니다.
