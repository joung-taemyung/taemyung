## 프롬프트를 쓰는 습관 {#habits}

1. **근거를 함께 요구한다** — 인용은 원문 그대로 + 위치, 숫자는 공식 + 대입한 값 + 계산 코드.
2. **받은 뒤 확인한다** — 인용은 원문에서 ++ctrl+f++ 로 찾고, 숫자는 코드로 다시 계산한 값과 맞춘다.
3. **틀린 곳만 짚어 되묻는다** — 처음부터 다시 시키지 않고 "3번 행 인용이 원문에 없다, 그 행만 다시"처럼 말한다.
4. **잘 된 프롬프트는 저장한다** — `workbench/day1/prompts/`에 이름 + 판 번호로(예: `A1_위험신호_v2.md`) 두고, 고칠 때마다 커밋합니다. 프롬프트도 코드처럼 이력을 남깁니다.
5. **허락 창은 읽고 승인한다** — Claude Code가 파일을 바꾸거나 명령을 실행하기 전에 묻습니다. 무엇을 · 어디에 · 지우는지 세 가지를 읽고 `1 Yes`를 누릅니다. 파일 삭제 · 강제 push · `git reset --hard` 같은 명령은 거절합니다.
6. **사람이 할 일은 사람이** — 옮겨 적기 · 표 만들기 · 커밋은 AI에게 맡기고, '일치/불일치'처럼 **내가 확인한 사실**과 코드 판단 · 원인 한 줄은 내가 씁니다. 그래서 보조 프롬프트는 끝이 늘 "어느 쪽이 맞는지는 쓰지 마"입니다.

## A0 · CLAUDE.md에 내 규칙 더하기 {#a0}

**도구** Claude Code(Manual) · **실습 A-1 · 04** · 결과 `CLAUDE.md`(첫 커밋 대상)

저장소에는 `CLAUDE.md`가 **이미 들어 있습니다.** 새로 만들지 않고 열어서 읽은 뒤, 내 업무에 맞는 규칙 두 줄을 더합니다. 빈 프로젝트에서 처음 만들 때만 `/init`으로 초안을 받습니다.

<!-- --8<-- [start:a0] -->
```text
@CLAUDE.md 를 읽고, '일하는 방식' 맨 아래에 내 업무 규칙 두 줄을 더해 줘.
- {내 규칙 ①}
- {내 규칙 ②}
다른 줄은 고치지 마. 바뀔 내용(diff)을 먼저 보여 줘.
```
<!-- --8<-- [end:a0] -->

**규칙 예**(그대로 써도 됩니다 — 회사 이름 · 실명 · 실제 숫자는 쓰지 않습니다. 이 저장소는 공개입니다)

- 숫자에는 기준일과 통화(또는 단위)를 함께 쓴다.
- 외국어 문서의 인용은 원문 그대로 두고 번역은 따로 쓴다.
- 메일은 초안 파일로만 만들고 보내지 않는다.
- 추정한 값에는 '추정'이라고 표시한다.

**확인** Claude는 보통 바뀔 내용(diff)을 대화에 먼저 보여 주고 "적용할까요?"라고 묻습니다 — 내가 더한 줄만 바뀌는지 보고 "응, 적용해 줘"라고 답하면 편집 허락 창이 뜹니다. 허락 창 오른쪽의 diff에서도 **내가 더한 줄만** 바뀌는지 봅니다. 다른 줄이 바뀌면 `No`로 거절하고 "다른 줄은 고치지 마"를 다시 말합니다.

## 채팅 경로 — Claude Code를 못 쓸 때 {#chat-path}

Claude Code 계정이 없거나(무료 플랜은 쓸 수 없습니다) 확장이 로그인되지 않으면, **claude.ai 또는 ChatGPT**에 파일을 올려 같은 일을 합니다. 프롬프트는 같고, 아래 세 가지만 바꿉니다.

| 바꿀 곳 | 어떻게 |
|---|---|
| `@파일` 줄 | 지웁니다. 대신 **파일을 첨부**합니다(보고서 `.md` · `d1_buyers_raw.xlsx` 또는 `.csv`). ChatGPT 무료는 하루 업로드 수가 적으니 Claude를 먼저 권합니다 |
| "결과는 outputs 폴더에 … 저장해" 줄 | **"결과를 `{파일 이름}` 파일로 만들어 내려받게 해 줘"**로 바꿉니다. 두 서비스 모두 파일을 만들어 줍니다 — 손으로 옮겨 적지 않습니다 |
| 코드 파일(`scripts/…`)과 노트북 | A2는 "계산 코드를 답에 보여 주고 실행해 줘", B4는 "노트북 대신 **코드를 실행해 차트 PNG 3개**와 해석 md를 만들어 내려받게 해 줘"로 바꿉니다 |

받은 파일은 GitHub 웹 화면(내 저장소 → `workbench/day1/outputs/` → **Add file → Upload files**)으로 올리고 커밋 메시지는 '무엇' · 빈 줄 · '왜'로 씁니다. 자세한 순서는 [실습 A의 채팅 경로](../day1/lab-a.md#chat-path)에 있습니다.

!!! warning "데이터 위생"
    이 프롬프트는 가상(합성) 데이터와 공개 공시용입니다. 회사 실데이터는 익명화한 것이라도 올리지 않습니다. 쓰는 AI의 '모델 개선(학습)' 설정은 끄고 시작합니다.
