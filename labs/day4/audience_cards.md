# 독자 카드 3종 — 같은 숫자, 읽는 사람에 따라 다른 모양 (실습 B 03)

카드 한 장을 고릅니다. 숫자는 **코드가 만든 값**(경보 엔진의 결과 · 지표 JSON)이고, 문장과 모양만 독자에 맞춰 바뀝니다. 어느 카드든 같은 규칙을 지킵니다 — 입력에 없는 숫자를 쓰지 않는다 · 조치는 "권고(사람 승인 전)" · 숫자는 대조한다 · 확정은 사람이 한다.

| 카드 | 독자 | 읽는 시간 | 만드는 것 | 만드는 도구 |
|---|---|---|---|---|
| ① 경영진 Word 2쪽 | 대표 · 임원 | 3분 | 요약 3줄 · 포트폴리오 · 주의 바이어 5곳 · 한도 재배정 · 시나리오 · 경보 · 결정 요청 표(승인 주체) · 가정과 한계 | 해석 프롬프트(B2-CC는 Claude Code, B2는 Claude · ChatGPT) → `make_report.py`(Word 템플릿) → `check_numbers.py` |

## 카드 ① 경영진 Word 2쪽 — 제공 스크립트로

1. 입력: 지표 JSON `workbench/day4/data/d4_report_input.json`(작업 사본 — 원본은 `data/checkpoints/`, 4일차 15:00부터 받는 파일). 오전 시연 1 · 2 · 4의 결과 파일에서 **코드가 모은 숫자**라 사람도 AI도 옮겨 적지 않았습니다. 칸 이름은 `labs/day4/report_schema.json`이 정합니다.
2. Claude Code에 **B2-CC**를 보내 `workbench/day4/outputs/narrative.json`을 파일로 바로 받습니다(채팅을 쓴다면 **B2** — 답에서 코드 블록 표시 ```를 빼고 `{`로 시작하게 저장).
3. `uv run python labs/day4/make_report.py` → `workbench/day4/outputs/credit_report_2026-09.docx`. '멈춤: docxtpl 이 없습니다'가 나오면 `uv sync`를 한 번 한 뒤 다시 돌립니다(`docxtpl`은 과정 환경에 들어 있습니다).
4. `uv run python labs/day4/check_numbers.py` → 불일치 0이어야 다음 단계로(불일치가 있으면 `prompts.md`의 B4-고침).

## 카드 ② 영업팀 바이어별 조치표 — 엑셀

- 입력: 내 경보 엔진의 결과 `workbench/day4/outputs/alerts.csv` · `alert_summary.json`.
- **바이어 한 곳에 한 줄**(경보가 여러 개면 가장 높은 등급의 조치). 열: 바이어(buyer_id) · 단계(D-3 · D+7 · D+15 · D+30 · 선적 보류) · 조치(권고 문장) · 담당 · 기한 · 등급(P1–P4) · 함께 걸린 규칙. 등급이 높을수록 위에, P1은 빨강 · P2는 주황 칸.
- 담당과 기한은 AI가 지어내지 않게 규칙을 준다 — 단계 사다리(D-3 · D+7 → 담당자 승인 / D+15 → 영업 담당 참조 / D+30 · 선적 보류 → 채권관리팀장 / 통지 기한 → 대표 결재)와 '기한 = 기준일 + 며칠'을 프롬프트에 적는다(B3 카드 ②).
- 확인: **표의 바이어 수**와 그중 **선적 보류 바이어 수**(= `alert_summary.json`의 `ship_hold.count`). 기본 규칙이면 바이어 30곳 · 선적 보류 19곳이고, 내 규칙이 바이어를 더하면 표가 더 길어진다 · 엑셀을 열어 서식이 적용됐는가.

## 카드 ③ 대표 보고 메일 5줄 — 텍스트

- 입력: 지표 JSON(입력에 있는 숫자만 쓰게 한다).
- 형식: ① 결론 한 줄 ② 가장 큰 위험 숫자 하나(단위와 기준일 포함) ③ 이미 한 일(자동 경보 · 이슈 링크) ④ 결정 요청 하나(승인 주체와 "권고(사람 승인 전)") ⑤ 다음 확인 시각. 줄마다 한 문장, 전부 합쳐 5줄.
- Claude Code에서 하면 B3 카드 ③ 끝에 '파일로 저장' 한 줄을 붙여 `workbench/day4/outputs/ceo_mail.txt`로 바로 받는다.
- 확인: 메일 속 숫자는 04 레드팀에 함께 맡긴다 — B4의 `[숫자 표]` 줄이 숫자마다 지표 JSON의 위치를 찾아 준다. 사람은 그 표를 읽고 판단한다.
