카드 한 장을 고릅니다(짝과 다른 카드를 고르면 17:00 결과 공유가 풍성해집니다). 하는 일은 같습니다 — **손잡이 하나를 바꾸고 → 먼저 예측하고 → 돌려서 확인하고 → 한 줄로 해석**합니다. 카드 ①–⑤는 정책 숫자 하나(또는 열 하나)를 바꾸는 실험이라 새 폴더(worktree)에서 15분 안에 끝나고, ⑥–⑨는 더 하기입니다.

## 하는 법 (공통)

1. **원래 창에서 03 커밋을 확인합니다** — 커밋하지 않은 변경은 새 작업 폴더에 따라오지 않습니다(새 폴더에 `scripts/limits_lp.py`가 없으면 이것).
2. **예측을 먼저 사람이** 적습니다 — 원래 창(브랜치 `d4-limits`)의 `workbench/day4/experiments.md` '## 실험' 절에 한 줄: 목적함수가 늘까 줄까 · 걸린 제약이 바뀔까.
3. **새 작업 폴더**: VS Code 소스 제어 보기 → 저장소 줄의 `…` → Worktrees → Create Worktree… → 새 브랜치 `d4-exp`(카드 ①이면 `d4-cap80`처럼 이름을 붙여도 됩니다) → 새 창으로 열기. 새 폴더는 비어 있으니 그 창의 터미널에서 `uv sync` → `uv run python tools/get_day_files.py 4`부터 합니다.
4. **정책 값은 작업 사본에서 바꿉니다**: `workbench/day4/data/d4_params.csv`(원본 `data/checkpoints/`는 읽기만 — 저장소 규칙). 열은 `excel_name`(찾는 이름)과 `value`(값)입니다. 비율은 소수로 씁니다(0.8 = 80%).
5. 새 창의 Claude Code에 프롬프트 **A4**를 보냅니다 — 엔진이 사본을 읽도록 `--params`, 결과를 따로 두도록 `--out workbench/day4/outputs/exp`.
6. 새 창에서 같은 속성 테스트를 돌리고, **남길 실험만 커밋**합니다(`workbench/day4/outputs/exp/` + 바꾼 사본).
7. 원래 창으로 돌아와 프롬프트 **A4-가져오기** — 결과 폴더만 `git checkout {실험 브랜치} -- workbench/day4/outputs/exp`로 가져오고(병합하지 않습니다), AI가 결과 한 줄을 시트 값 그대로 씁니다. **예측과 맞았나**는 내가 한 단어로 씁니다.

```text

- 바꾼 것: TotalCapShare 0.7 → 0.8 (workbench/day4/data/d4_params.csv)
- 예측(사람, 돌리기 전): 목적함수 증가, 걸린 제약은 총액 하나
- 결과(AI, 시트 값 그대로): 목적함수 3,135,799 → … (차이 …) · 걸린 제약 … · 잠재가격 …
- 예측과 맞았나: …
- 한 줄 해석: …
```

**같은 테스트로 확인하기** — 실험 결과도 속성 테스트로 봅니다. 정책 값 파일과 결과 파일의 경로를 줍니다(기준값이 아니므로 기대값 테스트는 일부러 어긋납니다 — 어긋난 폭이 곧 실험 결과입니다).


### 카드 ⑤의 힌트

`d4_start_scored.csv`에는 등급 열이 둘 있습니다 — `grade`(3일차 임계값 t/4 · t/2 · t 규칙)와 `grade_quantile`(순위 분위수). 엔진에서 `grade`를 쓰는 곳은 등급별 정책 숫자(PD · 가산 · 상한 · 자기 감당 비율)를 찾는 곳과 B등급 비중 제약 두 군데입니다. 둘 다 같은 열을 쓰게 해야 합니다.

### 카드 ⑥ — Claude Code로 풀고 워크북과 견준다

`d4_limit_model.xlsx`는 같은 계산을 엑셀 수식과 해 찾기 모델로 만든 **완성본**입니다. 엑셀에서 해 찾기를 손으로 돌리지 않고, Claude Code에게 "`04_AR_Ledger`(채권 R1–R7) · `06_WeeklyGap`(주간 지출) · `07_Solver` 첫머리의 설명대로 최소비용 매각 모델을 `scipy.optimize.linprog`로 풀어 `workbench/day4/outputs/card6.md`에 매각 비율 · 비용 · 주별 누적 현금을 써 줘 — 수식 칸은 값이 저장돼 있지 않으니 설명과 숫자 칸으로 다시 계산해"라고 시킵니다. 결과는 `07_Solver` 셋째 줄의 **확인값**(최소 비용 · 매입 의뢰 채권)과 견줍니다. 엑셀 해 찾기로도 같은 답이 나옵니다(파일 › 옵션 › 추가 기능 › Excel 추가 기능 '이동' › '해 찾기 추가 기능' — 웹용 Excel에는 없습니다).

### 카드 ⑧ 가정 — [교육용 가정]

- 대상: 연체 인보이스가 있는 바이어 중 신용장 · 선수금 거래와 신용사건(`bankruptcy_flag`) 바이어를 뺀 곳 — 21곳. `d4_open_inv.csv`로 연체일수(dpd)를 구하고, 바이어마다 **가장 오래된 연체일수**로 단계를 정합니다.
- 변수: 바이어마다 이번 주 집중 회수 대상이면 1, 아니면 0.
- 필요 시간과 접촉했을 때의 회수 확률 상승(연체 잔액 기준): 연체 14일 이하 0.5시간 · +10% / 15–29일 1시간 · +20% / 30일 이상 2시간 · +30%.
- 제약: 담당자 시간 합계 ≤ 8시간. 목적: 기대 회수 증가(= 연체 잔액 × 상승률의 합) 최대화.
- 더 해 보기: 시간을 6시간으로 줄이면? 0·1 대신 0~1 연속 변수로 풀면(LP 완화) 시간 1시간의 가치(잠재가격)는?

### 카드 ⑨ 가정 — [교육용 가정]

- 원장: `d4_limit_model.xlsx`의 `04_AR_Ledger` R1–R7(단위 USD천), 주간 지출은 `06_WeeklyGap`. 카드 ⑥의 최소비용 매각 모델(매각 비율 0~1)이 출발점입니다.
- 새 선택: 채권마다 '조기결제 할인 제안'을 낼 수 있다 — 할인 1%(수락 확률 40%) 또는 2%(수락 70%). 제안하면 2주차에 (1 − 할인) 비율이 기대값으로 입금되고, 원래 기대입금은 빠집니다.
- 한 채권에는 매각과 할인 제안 중 하나만. 누적 현금(기대값)은 매주 0 이상. 목적: 비용(매각 비용 + 할인으로 깎인 금액의 기대값) 최소화.
- 더 해 보기: 은행 매입 한도를 10만 달러로 두면? 할인 2%는 한 번이라도 고르나?
