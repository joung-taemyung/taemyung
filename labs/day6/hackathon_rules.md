## 규칙 6가지

1. **팀** — 4인 × 5팀. 사전 설문을 보고 직무 · 결제방식 · AI 숙련도가 섞이게 강사가 편성한다. 공공조달 수강생이 3명 이상이면 한 팀으로 묶고 변형 카드 V1을 더한다. 팀 저장소는 5일차 17:31에 조장이 킷 템플릿으로 만든 **비공개** 저장소 `tradefin-kit-T{조}`다(팀원 · 강사는 협업자로 초대).
2. **카드** — 팀마다 주카드 1장(09:31 개봉) + 전 팀 공통 인젝트 2장(11:30 · 13:15). 카드 배정은 강사가 한다.
3. **재료와 도구** — 1–5일차 산출물(내 것 또는 강사 정답본), 팀 저장소의 킷 템플릿. 도구는 **Claude Code(VS Code 확장)** · ChatGPT · Claude · Git/GitHub. 검증되지 않은 새 도구는 들이지 않는다.
4. **원칙** — 저장소에는 가상 한빛정밀 데이터만 올린다. 메일은 DRY RUN(실제 발송 0건). 사람이 결정할 항목(한도 변경 · 선적 보류 · K-SURE 통지 · 바이어 발송)은 모든 표에서 빨간색으로 표시한다. AI 출력에는 근거(조항 · 파일)를 단다.
5. **제출** — 팀 = 15:50 `v1.0` 릴리스 링크. 개인 = 17:50 도입 기획서 · KPI · ROI, 17:05 사후 진단(비공개 폼 — 저장소에 올리지 않는다).
6. **심사** — 루브릭은 09:09에 강의장에서 다시 공개한다. 동료 투표는 총점과 별도인 상으로만 쓴다.

AI와 시스템은 초안까지만 만든다. 결정 · 근거 · 결정자 · 시각을 남긴다. PR 병합 버튼도 사람이 누른다.

## 하지 말 것

- 회사 실데이터 · 익명화본 · 실명 · 실제 이메일 · API 키를 저장소나 프롬프트에 넣지 않는다.
- 메일을 실제로 보내지 않는다(초안과 승인 기록까지).
- AI가 낸 숫자 · 조항을 확인 없이 쓰지 않는다 — 원본 파일 · 원문에서 찾고, 없으면 '확인 필요'.
- 규정 · 법 해석이 필요한 판단을 AI가 단정하게 두지 않는다 — '확인 필요'로 넘기고 확인할 사람(관세사 · 법무 · K-SURE 등)을 적는다.
- '15/1000'을 일반 규칙처럼 쓰지 않는다(약관 제21조③에만 걸린 조항).
- 승인 창을 읽지 않고 누르지 않는다 — `use auto mode` · 일괄 허용(`allow all edits`)은 고르지 않고, 한 건씩 읽고 `1 Yes`한다.

## 인젝트가 오면

투입 시각에 전원 기립 → 손을 멈추고 10분 안에 팀의 대응 방향을 정한다 → 결과를 SOP와 `decision_log`에 반영한다. 인젝트 반영은 심사 기준 ①에 들어간다.

## 막히면 — 감점 없음

막히면 **그 AI에게 오류 메시지 전문을 먼저 → 팀 → 노트북 위에 빨간 표시(스티커)** 순서다. 20분 넘게 막히면 강사 정답본으로 합류하고 README 3번에 어느 단계에서 합류했는지 적는다.

| 상황 | 이렇게 |
|---|---|
| Claude Code가 안 된다(설치 · 로그인 · 사용량 한도 · 무료 계정) | ChatGPT 또는 Claude(웹)에 카드 · 팀 팩을 올려 같은 표를 만든다 → 결과 파일을 GitHub 웹(Add file → Upload files)으로 커밋. 실습 A · B 페이지의 '채팅 경로' |
| 새 폴더(worktree)에서 파이썬이 안 돈다 | 새 작업대에는 `.venv`가 없다 — `uv sync`부터 |
| GitHub이 막힘 · 계정 문제 | 저장소 관리자 1명만 올린다(팀원은 오픈채팅 · Drive로 전달) → 최악이면 zip `d6_team_solution__T{조}.zip` + README |
| `gh` 명령이 안 된다 | GitHub 웹에서 같은 일을 한다(이슈 · PR · Releases → Draft a new release) |
| 한도 최적화(LP)가 안 풀린다 | 등급 상한 규칙으로 근사하고 쓴 경로를 README에 적는다 → 4일차 `scripts/limits_lp.py`가 있으면 그것을 `ref/`에 둔다 |
| 대시보드(앱)가 잠들거나 안 열림 | **Yes, get this app back up!** → 강사 앱 URL → 스크립트가 낸 `alerts.csv`로 대신 보여 준다 |
| 체크포인트에 못 미침 | 오후 우선순위 카드의 '최소 완료 경로' · 강사 정답본으로 합류 |
| 팀원이 빠짐 | 3인: ④를 ⑤가 겸임 / 2인 이하: 강사와 상의(다른 팀 합류 또는 축소 카드) |
